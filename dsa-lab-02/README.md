**Name:** Abdul Rehman

## What this lab covers

Working with pointers, pointer arithmetic, dynamic memory allocation using `new` and `delete`, and 2D dynamic arrays.

## Tasks

- **Task 1:** Uses a pointer to traverse a 1D array of 5 sales values, computes the total, adds 2 to the third element, and prints the updated total.
- **Task 2:** Dynamically allocates an array of student marks (size entered at runtime), validates input, then prints the total, average, and how many students passed.
- **Task 3:** Uses a pointer-to-row to access a 2D array (2 branches x 3 days), then prints each branch total and each day total.
- **Task 4:** Allocates a 2D array dynamically using a double pointer (students x subjects), prints each student's total, and identifies the top student.
- **Task 5:** Allocates a dynamic array, copies it into a larger block to fit one extra student, and frees the original.
- **Task 6:** Basic example of allocating a dynamic array with `new`, filling it, printing it, and releasing it with `delete[]`.
